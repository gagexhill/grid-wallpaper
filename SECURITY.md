# Security Policy

## Supported versions

Security fixes target the [current published preview](https://github.com/gagexhill/grid-wallpaper/releases). Check the release notes for its supported Windows and Lively setup.

## Reporting a vulnerability

Use GitHub's private [Report a vulnerability](https://github.com/gagexhill/grid-wallpaper/security/advisories/new) form. Include the affected release, Windows and Lively versions, a minimal reproduction, and the expected impact. Remove personal paths and account information from attachments. Keep installed host configuration and session files private.

If private reporting is unavailable, open an issue requesting a private channel without including vulnerability details.
