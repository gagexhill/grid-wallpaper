# Code of Conduct

Treat other participants with respect. Welcome different experience levels, keep criticism about the work, and give people room to ask questions and correct mistakes.

Harassment, threats, discriminatory language, personal attacks, and publishing someone else's private information without consent are unacceptable.

This applies in the repository, issues, pull requests, Discussions, and other spaces where someone represents the project. The maintainer may remove harmful content or restrict participation. Use GitHub's reporting tools for abusive content or conduct. Report software vulnerabilities through the [Security Policy](SECURITY.md).
